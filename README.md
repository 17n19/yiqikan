# 💞 ดูด้วยกัน · 一起看

เว็บแอปไฟล์เดียว (`index.html`) ดูหนัง / แชร์จอ / มินิเกม กับแฟนที่อยู่ไกล — P2P (WebRTC) ไม่มีเซิร์ฟเวอร์ ไม่ใช้ CDN
ใช้ได้ทั้งคอมฯ และมือถือ (iPhone: Safari iOS 15.4+ · Android: Chrome)

## ขึ้น GitHub Pages
1. สร้าง repo (Public) เช่น `watch-together` → อัปโหลด `index.html`
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
3. เปิด `https://<username>.github.io/watch-together/`
   (ต้องเป็น https — มือถือจะเปิดไมค์/กล้องไม่ได้ถ้าไม่ใช่ https)

**ถ้าฝั่งจีนเปิด github.io ไม่ได้:** ต่อ repo เดียวกันเข้า Cloudflare Pages / Vercel / Netlify (ฟรี, deploy อัตโนมัติจาก GitHub) เพื่อได้ลิงก์สำรอง
หรือถ้าแฟนใช้คอมฯ ส่งไฟล์ `index.html` ทาง WeChat แล้วเปิดในเครื่องได้เลย

## เชื่อมต่อ (บนมือถือง่ายสุด)
1. คุณกด **สร้างห้อง** → กด **📤 ส่งต่อ** → เลือก WeChat → ส่งลิงก์เชิญให้แฟน
2. แฟนกดลิงก์ (ใน WeChat ให้กด ⋯ → เปิดในเบราว์เซอร์) → โค้ดถูกใส่ให้อัตโนมัติ → **สร้างโค้ดตอบกลับ** → **📤 ส่งต่อ** กลับมา
3. คุณคัดลอกโค้ดนั้น → **📋 วาง** → **เชื่อมต่อ** 💞
> สลับไปแอปแชทแล้วต้องกลับมาหน้าเดิม อย่าปิดแท็บ

## บนมือถือทำอะไรได้
| ฟีเจอร์ | มือถือ |
|---|---|
| ดูหนังไฟล์เดียวกันแบบซิงก์ | ✅ (ใช้ .mp4 H.264 — iPhone เล่น .mkv ไม่ได้) |
| ดูจอที่แฟนแชร์จากคอมฯ | ✅ |
| แชร์จอจากมือถือ | ❌ เบราว์เซอร์มือถือไม่รองรับ |
| เต็มจอ + แชทลอยบนจอ + อีโมจิ | ✅ (Android หมุนแนวนอนให้อัตโนมัติ) |
| แชท / ไมค์ / กล้องหน้า / ปุ่มคิดถึง (สั่น) / มินิเกม | ✅ |

## 💬 ซับ 3 ภาษา (ไทย · English · 中文)
- กด **💬 ซับ 3 ภาษา** (หรือปุ่ม **CC** บนจอ) → **โหลดซับ** เลือกได้หลายไฟล์พร้อมกัน — รองรับ `.srt` `.vtt` `.ass`
- ระบบดูภาษาจากชื่อไฟล์/เนื้อหาให้เอง และอ่าน encoding เก่าได้ (TIS-620 ไทย, GBK/Big5 จีน, UTF-16)
- ไฟล์ซับจีนที่มี 中文+English ในบรรทัดเดียวกัน จะแยกเป็น 2 ภาษาให้อัตโนมัติ
- **โหลดคนเดียวพอ** ซับจะถูกส่งให้แฟนเอง · แต่ละคนเลือกเปิดภาษาที่อยากดูเองได้ (เปิดพร้อมกัน 2–3 ภาษาก็ได้)
- ซับไม่ตรงเวลา กด −0.5 / +0.5 (ปรับให้ทั้งสองฝั่ง) · ปรับขนาดตัวอักษรและพื้นหลังได้
- ใช้ปุ่ม ⛶ ของแอปเพื่อเต็มจอ (ถ้า iPhone เข้าเต็มจอของระบบเอง ซับยังขึ้นแต่ใช้หน้าตาของ iOS)

## ต่อไม่ติด / กระตุก
- ให้ฝั่งใดฝั่งหนึ่งใช้ hotspot มือถือ หรือใส่ TURN server ใน ⚙️
- แชร์จอกระตุก: ดูแถบสถิติบนคอมฯ — `bandwidth` = ลดเป็น 720p, `cpu` = เปลี่ยนเป็น H.264
- Netflix/Disney+ แชร์แล้วจอดำ (DRM) — ใช้โหมดไฟล์หนังแทน
